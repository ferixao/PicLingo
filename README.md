# PicLingo

اپ اندرویدی ترجمه گروهی تصاویر با رابط فارسی/انگلیسی.

## امکانات نسخه اولیه
- انتخاب چند تصویر (تا سقف ۱۰۰ تصویر در صف برنامه)
- OCR با Google ML Kit
- ترجمه با مدل‌های on-device گوگل (مدل زبان در اولین استفاده دانلود می‌شود)
- ورق‌زدن تصاویر با swipe
- کپی متن ترجمه‌شده
- انتخاب زبان مبدأ و مقصد
- تم تیره بنفش/آبی

## ساخت APK
این پروژه Android Studio / Gradle است و به JDK 17 و Android SDK 35 نیاز دارد.

از ریشه پروژه اجرا کنید:
```bash
gradle :app:assembleDebug
```
خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## ساخت خودکار در GitHub
فایل `.github/workflows/build.yml` با هر push به شاخه `main` یا اجرای دستی workflow، APK را می‌سازد و به عنوان Artifact با نام `PicLingo-debug-apk` منتشر می‌کند.

## نکته
این یک نسخه اولیه قابل توسعه است. ترجمه ML Kit برای زبان‌های انتخاب‌شده به دانلود مدل نیاز دارد و ترجمه در دستگاه انجام می‌شود.
