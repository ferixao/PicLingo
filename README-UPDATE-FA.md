# بسته به‌روزرسانی PicLingo 1.1

این بسته فایل‌های لازم برای به‌روزرسانی سورس فعلی را دارد.

## تغییرات
- بازطراحی رابط کاربری با رنگ‌بندی بنفش/آبی
- انتخاب خودکار تم روشن/تاریک بر اساس تنظیمات گوشی
- نمایش ترجمه هر بلوک متن روی محدوده همان متن در عکس
- اضافه‌شدن OCR برای لاتین، چینی، هندی/دوناگری، ژاپنی و کره‌ای
- حفظ انتخاب گروهی تا ۱۰۰ تصویر، ورق‌زدن، کپی ترجمه و انتخاب زبان
- افزایش نسخه به 1.1.0

## محدودیت فعلی OCR
Google ML Kit bundled Text Recognition در این نسخه برای لاتین، چینی، دوناگری، ژاپنی و کره‌ای مدل دارد. تشخیص متن مبدأ فارسی، عربی و سیریلیک (روسی) در این نسخه فعال نیست. ترجمه به فارسی و عربی پشتیبانی می‌شود؛ یعنی برای نمونه English -> Persian قابل استفاده است.

## نصب تغییرات در سورس
ZIP را در پوشه Downloads گوشی ذخیره کنید، سپس در Termux:
1. به پوشه مخزن بروید.
2. ZIP را در ریشه مخزن استخراج کنید.
3. تغییرات را commit و push کنید.
4. GitHub Actions نسخه جدید APK را می‌سازد.

آیکون برنامه با همان تصویر PNG لوگویی که کاربر فرستاده جایگزین شده است.
